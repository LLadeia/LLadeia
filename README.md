## 🚀 Projetos em destaque

### 🏥 API de Agendamentos para Clínicas Médicas — TFG

Sistema completo de agendamento de consultas para clínicas de pequeno e médio porte, com API REST e front-end web para a recepção, os médicos e os pacientes. É o meu Trabalho Final de Graduação.

![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=flat-square&logo=postgresql&logoColor=white)
![SQLAlchemy](https://img.shields.io/badge/SQLAlchemy-D71F00?style=flat-square&logo=sqlalchemy&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)
![GitHub Actions](https://img.shields.io/badge/GitHub_Actions-2088FF?style=flat-square&logo=github-actions&logoColor=white)

- **Controle de faltas por regras, sem IA:** consulta sem check-in vira falta automaticamente, gera alerta para a recepção e identifica o paciente faltoso recorrente
- **Agenda por profissional:** horários por dia da semana, feriados, bloqueios e remarcação em uma só operação
- **Área do médico:** pacientes do dia, anotações de consulta, receitas e exames em PDF
- **Segurança:** JWT com RBAC, bloqueio de login após tentativas erradas e registro de quem abriu cada ficha (LGPD)
- **Qualidade:** 222 testes automatizados com 99% de cobertura; CI com lint, testes, verificação de migrações e build das imagens Docker

🔒 Repositório privado por enquanto.

### 📦 [StockControl](https://github.com/LLadeia/StockControl)

Sistema full-stack de controle de estoque de matérias-primas e planejamento de produção industrial.

![Django](https://img.shields.io/badge/Django-092E20?style=flat-square&logo=django&logoColor=white)
![Django REST](https://img.shields.io/badge/Django_REST-ff1709?style=flat-square&logo=django&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![SQLite](https://img.shields.io/badge/SQLite-07405E?style=flat-square&logo=sqlite&logoColor=white)

- API com **Django REST Framework** e autenticação **JWT**
- Associação produto × matéria-prima (Bill of Materials)
- Algoritmo que calcula o que pode ser produzido com o estoque disponível, priorizando os itens de maior valor
- Histórico de produção com métricas de receita
- Interface em **React + Vite** com tema escuro
